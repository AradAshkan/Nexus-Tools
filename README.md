# Nexus Tools

A sleek, modern utility suite built with pure HTML, CSS, and JavaScript. Nexus Tools delivers fast conversions and date calculations in a dark-themed interface with bold red accents, responsive layouts, and intuitive controls.

[![Dark Theme](https://img.shields.io/badge/theme-dark-red?style=flat&logo=css3)](https://github.com)
[![Vanilla JS](https://img.shields.io/badge/vanilla-JS-yellow?style=flat&logo=javascript)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)
[![Responsive](https://img.shields.io/badge/responsive-mobile%20friendly-brightgreen?style=flat)](https://developer.mozilla.org/en-US/docs/Web/CSS)

## Features

- ⚡ Timestamp converter: Unix seconds ↔ human readable date/time
- 🕒 Live millisecond counter updated every second
- 📏 Length conversion: cm, m, mm, km
- ⚖️ Weight conversion: kg, g, lb, oz
- 🌡️ Temperature conversion: °C, °F, K
- 📅 Date difference calculator with days, hours, and minutes
- 🖤 Dark theme with red accent styling and glassmorphism effects
- 📱 Fully responsive layout for desktop, tablet, and mobile
- ✅ Clean, dependency-free HTML5/CSS3/JavaScript implementation

## Installation

1. Clone or download the project files
   ```bash
   git clone https://github.com/aradashkan/nexus-tools.git
   ```
2. Open `index.html` in your browser
3. No build step required

## Usage

1. Open `index.html`
2. Use the sidebar to switch between tools
3. Enter values and press the convert/calculate buttons
4. View results in the highlighted result panels
